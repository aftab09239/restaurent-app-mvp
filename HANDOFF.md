# Handoff

The final working tree is intended for Assignment 1 submission. Start with:

```bash
npm install
npx expo start
```

Use the mock credentials in README. The project is frontend-only and stores orders, reservations and manager menu edits with AsyncStorage.

The main runtime implementation remains in `App.js`; supporting contexts, reducers, hooks, data, screen contracts and navigation route definitions are organized under `src/` for assignment traceability.
